# 🗳️ DOA Token – Governance Proposals  
# 🗳️ DOA Token – Propuestas de Gobernanza

Este documento registra todas las propuestas creadas por la comunidad y el equipo relacionadas con la gobernanza del DOA Token.  
Cada propuesta debe incluir detalles claros para su evaluación y votación.  
This document records all proposals created by the community and the team related to DOA Token governance.  
Each proposal must include clear details for evaluation and voting.  

---

## 📋 Formato de Propuesta / Proposal Format

- **ID:** Número único de la propuesta (ej. P-001) / Unique proposal number (e.g., P-001)  
- **Fecha / Date:** YYYY-MM-DD  
- **Título / Title:** Breve descripción de la propuesta / Short description of the proposal  
- **Autor / Author:** Nombre o dirección del proponente / Name or address of the proposer  
- **Área / Area:** Técnico | Legal | Comunidad | Financiero / Technical | Legal | Community | Financial  
- **Contenido / Content:** Descripción detallada de la propuesta / Detailed description of the proposal  
- **Motivo / Reason:** Razón por la cual se presenta la propuesta / Reason for presenting the proposal  
- **Estado / Status:** `draft` | `active` | `approved` | `rejected`  
- **Snapshot Block:** Número de bloque usado para calcular votos / Block number used to calculate votes  
- **Resultados / Results:** Documentar en `governance-log.md` / Document in `governance-log.md`
