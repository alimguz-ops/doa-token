## 📋 Formato de Registro / Log Format

- **Fecha / Date:** YYYY-MM-DD  
- **Responsable / Responsible:** Nombre o entidad / Name or entity  
- **Área / Area:** Técnico | Auditoría | Legal | CEX | Comunidad / Technical | Audit | Legal | CEX | Community  
- **Estado / Status:** breve descripción del cambio o avance / brief description of the change or progress  
- **Notas / Notes:** comentarios adicionales o enlaces de verificación / additional comments or verification links
