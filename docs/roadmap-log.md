# 📜 DOA Token – Roadmap Log  
# 📜 DOA Token – Registro de Roadmap

Este archivo registra cronológicamente cada actualización o ajuste realizado al roadmap del proyecto DOA Token.  
Sirve como bitácora transparente para auditores, colaboradores y comunidad.  
This file chronologically records each update or adjustment made to the DOA Token project roadmap.  
It serves as a transparent log for auditors, collaborators, and the community.  

---

## 📋 Formato de Registro / Log Format

- **Fecha / Date:** YYYY-MM-DD  
- **Responsable / Responsible:** Nombre o entidad / Name or entity  
- **Cambio / Change:** Descripción breve del ajuste en el roadmap / Brief description of the roadmap adjustment  
- **Motivo / Reason:** Razón del cambio (ej. liquidez, adopción, auditoría, requisitos legales, feedback de comunidad) / Reason for the change (e.g., liquidity, adoption, audit, legal requirements, community feedback)  
- **Estado / Status:** `planned` | `in-progress` | `completed`  
- **Enlaces / Links:** URL a documentación, auditorías o comunicados oficiales relacionados / URL to documentation, audits, or related official announcements  

---

- **Fecha / Date:** 2026-03-31  
- **Responsable / Responsible:** Equipo DOA / DOA Team  
- **Cambio / Change:** Ajuste en Q2 2026 – se añade aplicación a dos CEX adicionales. / Adjustment in Q2 2026 – application to two additional CEX added.

  - Comunicado oficial en Twitter / Official announcement on Twitter
