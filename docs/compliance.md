# ⚖️ DOA Token – Compliance Framework  
# ⚖️ DOA Token – Marco de Cumplimiento

Este documento define las políticas y certificaciones de cumplimiento regulatorio del DOA Token.  
Su objetivo es garantizar transparencia, seguridad jurídica y confianza frente a exchanges, auditores y comunidad.  
This document defines the regulatory compliance policies and certifications of the DOA Token.  
Its purpose is to ensure transparency, legal security, and trust for exchanges, auditors, and the community.  

---

## ⚖️ Principios de Cumplimiento / Compliance Principles

1. **Legalidad / Legality:** El DOA Token no constituye un valor financiero según certificación legal. / DOA Token is not considered a financial security according to legal certification.  
2. **Transparencia / Transparency:** Toda documentación AML/KYC debe estar disponible para auditores y exchanges. / All AML/KYC documentation must be available to auditors and exchanges.  
3. **Responsabilidad / Responsibility:** El equipo debe mantener registros claros y actualizados en `legal/`. / The team must maintain clear and updated records in `legal/`.  
4. **Adaptabilidad / Adaptability:** Las políticas se ajustan conforme evoluciona la regulación en cada jurisdicción. / Policies are adjusted as regulations evolve in each jurisdiction.
