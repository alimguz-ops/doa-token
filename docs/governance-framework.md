# 🏛️ DOA Token – Governance Framework  
# 🏛️ DOA Token – Marco de Gobernanza

Este documento define la estructura de gobernanza del ecosistema DOA Token.  
Su objetivo es garantizar transparencia, participación comunitaria y procesos claros de toma de decisiones.  
This document defines the governance structure of the DOA Token ecosystem.  
Its purpose is to ensure transparency, community participation, and clear decision-making processes.  

---

## 🏛 Principios de Gobernanza / Governance Principles

1. **Transparencia / Transparency:** Todas las decisiones deben registrarse públicamente en `governance-log.md`. / All decisions must be publicly recorded in `governance-log.md`.  
2. **Participación / Participation:** Los holders de DOA Token tienen derecho a votar en propuestas clave. / DOA Token holders have the right to vote on key proposals.  
3. **Responsabilidad / Accountability:** Los resultados de votación deben implementarse y documentarse. / Voting results must be implemented and documented.  
4. **Seguridad / Security:** Los procesos de gobernanza deben estar protegidos contra manipulación y fraude. / Governance processes must be protected against manipulation and fraud.  

---

## 📋 Estructura / Structure

- **Comunidad / Community:** Holders de DOA Token con derecho a voto proporcional a su balance. / DOA Token holders with voting rights proportional to their balance.  
- **Equipo Técnico / Technical Team:** Encargado de implementar cambios aprobados. / Responsible for implementing approved changes.  
- **Auditores Externos / External Auditors:** Validan transparencia y cumplimiento. / Validate transparency and compliance.  
- **Asesores Legales / Legal Advisors:** Supervisan cumplimiento regulatorio. / Oversee regulatory compliance.  

---

## 🗳 Procesos de Votación / Voting Processes

- **Propuestas / Proposals:**  
  - Creadas por cualquier miembro de la comunidad. / Created by any community member.  
  - Registradas en `proposals.md`. / Recorded in `proposals.md`.  

- **Votación / Voting:**  
  - Cada DOA Token equivale a un voto. / Each DOA Token equals one vote.  
  - Se utiliza snapshot de balances en bloque específico. / A snapshot of balances at a specific block is used.  
  - Duración estándar: 7 días. / Standard duration: 7 days.  

- **Resultados / Results:**  
  - Documentados en `governance-log.md`. / Documented in `governance-log.md`.  
  - Implementados por el equipo técnico. / Implemented by the technical team.  

---

## 📑 Tipos de Propuestas / Types of Proposals

- **Técnicas / Technical:** Cambios en contratos, scripts o infraestructura. / Changes in contracts, scripts, or infrastructure.  
- **Legales / Legal:** Ajustes en políticas AML/KYC o certificación. / Adjustments in AML/KYC policies or certification.  
- **Comunitarias / Community:** Campañas, marketing, adopción. / Campaigns, marketing, adoption.  
- **Financieras / Financial:** Ajustes en supply, quema o liquidez. / Adjustments in supply, burn, or liquidity.
