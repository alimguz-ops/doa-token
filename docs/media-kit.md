# DOA Token – Media Kit

Este documento centraliza todos los recursos gráficos y visuales oficiales del proyecto DOA Token.  
Su objetivo es proporcionar materiales consistentes y listos para usar en auditorías, listados en exchanges y comunicación comunitaria.

---

## 📋 Contenido del Media Kit

- **Logo oficial**  
  - Formato PNG: `assets/doa-logo.png`  
  - Formato SVG: `assets/doa-logo.svg`  
  - Fondo transparente disponible.  

- **Iconografía**  
  - Ícono cuadrado (para apps y exchanges): `assets/doa-icon.png`  
  - Ícono circular (para redes sociales): `assets/doa-icon-circle.png`  

- **Paleta de colores oficial**  
  - Primario: #2D2D2D (gris oscuro)  
  - Secundario: #FFCC00 (amarillo dorado)  
  - Fondo: #FFFFFF (blanco)  
  - Acento: #0066FF (azul)  

- **Tipografía oficial**  
  - Títulos: Montserrat Bold  
  - Texto: Open Sans Regular  

- **Plantillas gráficas**  
  - Banner para redes sociales: `assets/banner-twitter.png`  
  - Portada para Telegram/Discord: `assets/banner-community.png`  
  - Plantilla para anuncios oficiales: `assets/announcement-template.png`  

---

## 📣 Uso del Media Kit

- Todos los materiales deben usarse sin alteraciones para mantener consistencia visual.  
- Los logos y banners oficiales deben acompañar cada anuncio en redes sociales y comunicados.  
- Los exchanges pueden utilizar estos recursos para listados y presentaciones públicas.  

---

## 📌 Notas

- Este archivo debe actualizarse cada vez que se añadan nuevos recursos gráficos.  
- Forma parte del paquete oficial junto con `announcement.md` y `community-metrics.md`.  
- La consistencia visual fortalece la identidad del proyecto y la confianza de la comunidad.
