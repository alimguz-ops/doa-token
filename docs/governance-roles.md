# 🧑‍🤝‍🧑 DOA Token – Governance Roles  
# 🧑‍🤝‍🧑 DOA Token – Roles de Gobernanza

Este documento define las responsabilidades específicas de cada actor dentro del sistema de gobernanza del DOA Token.  
Su objetivo es garantizar claridad en funciones, transparencia en procesos y responsabilidad compartida.  
This document defines the specific responsibilities of each actor within the DOA Token governance system.  
Its purpose is to ensure clarity in roles, transparency in processes, and shared accountability.  

---

## 👥 Comunidad / Community
- **Rol / Role:** Holders de DOA Token / DOA Token holders  
- **Responsabilidades / Responsibilities:**  
  - Crear propuestas en `proposals.md`. / Create proposals in `proposals.md`.  
  - Participar en votaciones con poder proporcional a su balance. / Participate in voting with power proportional to their balance.  
  - Promover transparencia y comunicación en canales oficiales. / Promote transparency and communication in official channels.  

---

## 🛠 Equipo Técnico / Technical Team
- **Rol / Role:** Desarrolladores y operadores del ecosistema DOA / Developers and operators of the DOA ecosystem  
- **Responsabilidades / Responsibilities:**  
  - Implementar cambios aprobados en contratos, scripts y documentación. / Implement approved changes in contracts, scripts, and documentation.  
  - Mantener registros en `changelog.md` y `releases.md`. / Maintain records in `changelog.md` and `releases.md`.  
  - Garantizar seguridad y reproducibilidad en cada actualización. / Ensure security and reproducibility in each update.  

---

## 📑 Auditores Externos / External Auditors
- **Rol / Role:** Firmas o entidades independientes de auditoría / Independent auditing firms or entities  
- **Responsabilidades / Responsibilities:**  
  - Validar que las implementaciones coincidan con lo aprobado en votaciones. / Validate that implementations match what was approved in votes.  
  - Emitir informes en `audit/audit-report.md`. / Issue reports in `audit/audit-report.md`.  
  - Supervisar cumplimiento técnico y financiero. / Oversee technical and financial compliance.  

---

## ⚖️ Asesores Legales / Legal Advisors
- **Rol / Role:** Expertos legales asociados al proyecto / Legal experts associated with the project  
- **Responsabilidades / Responsibilities:**  
  - Revisar certificaciones AML/KYC y de no-valor. / Review AML/KYC and non-security certifications.  
  - Garantizar cumplimiento regulatorio en cada jurisdicción. / Ensure regulatory compliance in each jurisdiction.  
  - Documentar revisiones en `legal/`. / Document reviews in `legal/`.
