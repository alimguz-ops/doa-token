# DOA Token – Changelog

Este documento registra todas las versiones y cambios técnicos realizados en el repositorio del DOA Token.  
Incluye actualizaciones de contratos, scripts, documentación y configuraciones.

---

## 📋 Formato de Registro

- **Fecha:** YYYY-MM-DD  
- **Versión:** vX.Y.Z  
- **Cambios:** Lista breve de modificaciones realizadas  
- **Responsable:** Nombre o entidad  
- **Notas:** Comentarios adicionales o enlaces de verificación  

---

## 📒 Ejemplo de Entrada

- **Fecha:** 2025-12-27  
- **Versión:** v1.0.0  
- **Cambios:**  
  - Deploy inicial del contrato DOA Token con proxy.  
  - Publicación de `tokenlist.json`.  
  - Inclusión de scripts de auditoría (`checkTotalSupply.js`, `checkAllBalances.js`).  
- **Responsable:** Equipo Técnico DOA  
- **Notas:** Confirmado en PolygonScan – [Proxy](https://polygonscan.com/address/0x692d951163df3f7D9Fe071413F92c319D9B7369E#code)

---

## 📌 Notas

- Cada cambio debe registrarse inmediatamente después de aplicarse.  
- Las versiones deben seguir el esquema **SemVer** (ej. v1.0.0, v1.1.0, v2.0.0).  
- Este archivo complementa `status-log.md` y `roadmap-log.md`.  
- La transparencia en cambios técnicos fortalece la confianza de la comunidad y exchanges.
