# 🗳️ DOA Token – Governance Log  
# 🗳️ DOA Token – Registro de Gobernanza

Este documento registra los resultados de cada propuesta sometida a votación dentro del sistema de gobernanza del DOA Token.  
Su objetivo es garantizar trazabilidad, transparencia y responsabilidad en la implementación de decisiones.  
This document records the results of each proposal submitted to voting within the DOA Token governance system.  
Its purpose is to ensure traceability, transparency, and accountability in decision implementation.  

---

## 📋 Formato de Registro / Record Format

- **ID:** Número único de la propuesta (ej. P-001) / Unique proposal number (e.g., P-001)  
- **Fecha / Date:** YYYY-MM-DD  
- **Título / Title:** Breve descripción de la propuesta / Short description of the proposal  
- **Autor / Author:** Nombre o dirección del proponente / Name or address of the proposer  
- **Área / Area:** Técnico | Legal | Comunidad | Financiero / Technical | Legal | Community | Financial  
- **Estado Final / Final Status:** `approved` | `rejected` | `withdrawn`  
- **Resultados / Results:** Número de votos a favor, en contra y abstenciones / Number of votes in favor, against, and abstentions  
- **Implementación / Implementation:** Acción tomada tras la votación / Action taken after voting  
- **Enlaces / Links:** URLs a `announcement.md`, `changelog.md`, `releases.md` o auditorías / URLs to `announcement.md`, `changelog.md`, `releases.md`, or audits
