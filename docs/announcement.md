# 📢 DOA Token – Official Announcements  
# 📢 DOA Token – Comunicados Oficiales

Este documento centraliza todos los comunicados oficiales relacionados con el DOA Token.  
Incluye anuncios de auditorías, listados en exchanges, eventos de quema y actualizaciones de comunidad.  
This document centralizes all official announcements related to the DOA Token.  
It includes audit notices, exchange listings, burn events, and community updates.  

---

## 📋 Formato de Registro / Record Format

- **Fecha / Date:** YYYY-MM-DD  
- **Título / Title:** Breve título del anuncio / Short announcement title  
- **Contenido / Content:** Descripción clara y concisa del comunicado / Clear and concise description of the announcement  
- **Enlaces / Links:** URLs a PolygonScan, auditorías, redes sociales o documentación oficial / URLs to PolygonScan, audits, social media, or official documentation  
- **Responsable / Responsible:** Equipo o entidad que emite el comunicado / Team or entity issuing the announcement
