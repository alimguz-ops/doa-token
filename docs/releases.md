# 🚀 DOA Token – Releases  
# 🚀 DOA Token – Publicaciones de Versiones

Este documento registra cada release oficial del proyecto DOA Token.  
Incluye notas de versión, cambios principales y enlaces de verificación.  
This document records each official release of the DOA Token project.  
It includes version notes, main changes, and verification links.  

---

## 📋 Formato de Registro / Record Format

- **Fecha / Date:** YYYY-MM-DD  
- **Versión / Version:** vX.Y.Z  
- **Tipo de release / Release type:** `major` | `minor` | `patch`  
- **Notas de versión / Version notes:** Lista breve de cambios y mejoras / Brief list of changes and improvements  
- **Responsable / Responsible:** Nombre o entidad / Name or entity  
- **Enlaces / Links:** URL a PolygonScan, auditorías, documentación o repositorio / URL to PolygonScan, audits, documentation, or repository
