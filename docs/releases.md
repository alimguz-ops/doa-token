# DOA Token – Releases

Este documento registra cada release oficial del proyecto DOA Token.  
Incluye notas de versión, cambios principales y enlaces de verificación.

---

## 📋 Formato de Registro

- **Fecha:** YYYY-MM-DD  
- **Versión:** vX.Y.Z  
- **Tipo de release:** `major` | `minor` | `patch`  
- **Notas de versión:** Lista breve de cambios y mejoras  
- **Responsable:** Nombre o entidad  
- **Enlaces:** URL a PolygonScan, auditorías, documentación o repositorio  

---

## 📒 Ejemplo de Entrada

- **Fecha:** 2025-12-27  
- **Versión:** v1.0.0  
- **Tipo de release:** major  
- **Notas de versión:**  
  - Deploy inicial del contrato DOA Token con proxy.  
  - Publicación de `tokenlist.json`.  
  - Inclusión de scripts de auditoría (`checkTotalSupply.js`, `checkAllBalances.js`).  
- **Responsable:** Equipo Técnico DOA  
- **Enlaces:**  
  - [Proxy en PolygonScan](https://polygonscan.com/address/0x692d951163df3f7D9Fe071413F92c319D9B7369E#code)  
  - [Implementación en PolygonScan](https://polygonscan.com/address/0xD6426Da6D01233Efe48dab6aD96cf3238f02c305#code)  

---

## 📌 Notas

- Cada release debe registrarse inmediatamente después de publicarse.  
- Las versiones deben seguir el esquema **SemVer** (ej. v1.0.0, v1.1.0, v2.0.0).  
- Este archivo complementa `changelog.md` (cambios técnicos) y `status-log.md` (estado puntual).  
- La transparencia en releases fortalece la confianza de la comunidad y exchanges.
