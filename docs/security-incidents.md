# 🛡️ DOA Token – Security Incidents Log  
# 🛡️ DOA Token – Registro de Incidentes de Seguridad

Este documento registra cronológicamente todos los incidentes de seguridad relacionados con el ecosistema DOA Token.  
Incluye descripción del incidente, impacto, acciones correctivas y comunicación oficial.  
This document chronologically records all security incidents related to the DOA Token ecosystem.  
It includes incident description, impact, corrective actions, and official communication.  

---

## 📋 Formato de Registro / Record Format

- **Fecha / Date:** YYYY-MM-DD  
- **Título / Title:** Breve descripción del incidente / Short description of the incident  
- **Descripción / Description:** Detalle del incidente detectado / Detailed description of the incident detected  
- **Impacto / Impact:** Evaluación del alcance (ej. bajo, medio, alto) / Scope assessment (e.g., low, medium, high)  
- **Acciones Correctivas / Corrective Actions:** Medidas tomadas para resolver el incidente / Measures taken to resolve the incident  
- **Estado / Status:** `resolved` | `ongoing` | `monitoring`  
- **Responsable / Responsible:** Equipo o entidad que gestionó la respuesta / Team or entity that managed the response  
- **Enlaces / Links:** URLs a transacciones, reportes o comunicados oficiales / URLs to transactions, reports, or official communications  

---

## 📒 Ejemplo de Entrada / Example Entry

- **Fecha / Date:** 2026-02-05  
- **Título / Title:** Intento de acceso no autorizado al repositorio / Unauthorized access attempt to repository  
- **Descripción / Description:**  
  Se detectó un intento de acceso no autorizado al repositorio principal del DOA Token.  
  An unauthorized access attempt was detected in the main DOA Token repository.  
- **Impacto / Impact:** Bajo – no se comprometieron claves ni contratos. / Low – no keys or contracts were compromised.  
- **Acciones Correctivas / Corrective Actions:**  
  - Revisión de permisos en GitHub. / Review of GitHub permissions.  
  - Activación de autenticación 2FA obligatoria. / Activation of mandatory 2FA authentication.  
  - Registro del evento en `security-policy.md`. / Event recorded in `security-policy.md`.  
- **Estado / Status:** resolved  
- **Responsable / Responsible:** Equipo Técnico DOA / DOA Technical Team  
- **Enlaces / Links:**  
  - Comunicado oficial en `announcement.md` / Official announcement in `announcement.md`  
  - Registro en `audit-log.md` / Record in `audit-log.md`
