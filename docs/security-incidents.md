# DOA Token – Security Incidents Log

Este documento registra cronológicamente todos los incidentes de seguridad relacionados con el ecosistema DOA Token.  
Incluye descripción del incidente, impacto, acciones correctivas y comunicación oficial.

---

## 📋 Formato de Registro

- **Fecha:** YYYY-MM-DD  
- **Título:** Breve descripción del incidente  
- **Descripción:** Detalle del incidente detectado  
- **Impacto:** Evaluación del alcance (ej. bajo, medio, alto)  
- **Acciones Correctivas:** Medidas tomadas para resolver el incidente  
- **Estado:** `resolved` | `ongoing` | `monitoring`  
- **Responsable:** Equipo o entidad que gestionó la respuesta  
- **Enlaces:** URLs a transacciones, reportes o comunicados oficiales  

---

## 📒 Ejemplo de Entrada

- **Fecha:** 2026-02-05  
- **Título:** Intento de acceso no autorizado al repositorio  
- **Descripción:**  
  Se detectó un intento de acceso no autorizado al repositorio principal del DOA Token.  
- **Impacto:** Bajo – no se comprometieron claves ni contratos.  
- **Acciones Correctivas:**  
  - Revisión de permisos en GitHub.  
  - Activación de autenticación 2FA obligatoria.  
  - Registro del evento en `security-policy.md`.  
- **Estado:** resolved  
- **Responsable:** Equipo Técnico DOA  
- **Enlaces:**  
  - Comunicado oficial en `announcement.md`  
  - Registro en `audit-log.md`  

---

## 📌 Notas

- Cada incidente debe registrarse inmediatamente después de detectarse.  
- Este archivo complementa `security-policy.md`, `audit-log.md` y `announcement.md`.  
- La transparencia en incidentes fortalece la confianza de la comunidad y exchanges.
