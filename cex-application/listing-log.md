# DOA Token – Listing Log

Este archivo registra todas las aplicaciones enviadas a exchanges centralizados (CEX) para el listado del DOA Token.  
Cada entrada debe incluir **fecha, exchange, estado y observaciones**.

---

## 📋 Formato de Registro

- **Fecha:** YYYY-MM-DD  
- **Exchange:** Nombre del CEX  
- **Estado:** `submitted` | `under review` | `approved` | `rejected`  
- **Observaciones:** Comentarios relevantes (ej. requisitos adicionales, tiempos de respuesta, documentación solicitada)  
- **Enlaces:** URL al formulario de aplicación o comunicación oficial  

---

## 📒 Ejemplo de Entrada

- **Fecha:** 2025-12-27  
- **Exchange:** Binance  
- **Estado:** submitted  
- **Observaciones:** Se adjuntó `application.md`, auditoría y certificación legal.  
- **Enlaces:**  
  - [Application Form](https://www.binance.com/en/listing)  
  - Registro interno: `cex-application/application.md`

---

## 📌 Notas

- Cada aplicación debe registrarse inmediatamente después de ser enviada.  
- El estado debe actualizarse conforme avance el proceso de revisión.  
- Este archivo es parte del paquete oficial de documentación junto con `application.md` y `requirements.md`.  
- La transparencia en el proceso de listado fortalece la confianza de la comunidad y los exchanges.
