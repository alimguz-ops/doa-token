## 🧾 Resumen ejecutivo / Executive Summary
- **ES:** DOA es un token diseñado para gobernanza, liquidez y expansión de aplicaciones descentralizadas.

El proyecto se centra en transparencia, cumplimiento regulatorio y liquidez verificable en Polygon.  
The project focuses on transparency, regulatory compliance, and verifiable liquidity on Polygon.

- **EN:**  
  - QuickSwap v2: Active WPOL/DOA pair, reserves auditable through internal monitoring scripts.
