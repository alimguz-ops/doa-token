# Aplicación a Exchanges Centralizados (CEX)

Esta carpeta contiene toda la documentación y formularios necesarios para solicitar el listado del token DOA en exchanges centralizados.

## Archivos incluidos
- **application.md** → Documento principal con requisitos y datos del token.
- **requirements.md** → Lista de requisitos solicitados por los exchanges.
- **listing-log.md** → Registro de solicitudes enviadas y estado de cada aplicación.
