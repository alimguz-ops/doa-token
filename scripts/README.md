# Scripts del Proyecto DOA

Esta carpeta contiene los scripts de automatización y monitoreo utilizados en el despliegue y operación del token DOA.

## Archivos incluidos
- **deploy.js** → Script de despliegue automático del contrato.
- **monitor-liquidez.js** → Script de monitoreo de reservas mínimas y alertas.
- **utils.js** → Funciones auxiliares para los scripts.
